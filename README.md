# MASC Stock

Gestion du stock de consommables d'imprimerie de MA SOFT CONSULTING :
produits, entrées, sorties, inventaire, livraisons par client et fiches
d'inventaire client (PDF / CSV).

Next.js 16 · React 19 · Supabase · Vercel
